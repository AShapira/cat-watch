Model, analysis and time filters

Cat filters use saved comparisons and live cat candidates and do not delete footage. Cat scores are model confidence, not human confirmation. Area matches use the percentage of each cat box overlapping the session polygons. A matching frame is candidate presence, not a confirmed visit.
